# Sistema de Gestión de Emergencias Médicas con Concurrencia

Sistema que simula la gestión concurrente de emergencias médicas para el Centro de Emergencias de la ciudad, asignando recursos limitados como ambulancias, equipos médicos y hospitales a incidentes que llegan en tiempo real con distinta gravedad.
